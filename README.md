# Yens Dad Project - Communication App

Aplikasi komunikasi web-based untuk membantu ayah Yens berkomunikasi setelah stroke. 

**Fitur:**
- ✅ Papan alfabet interaktif dengan huruf BESAR (75 tahun)
- ✅ Prediksi kata otomatis saat mengetik
- ✅ Frasa umum yang sering digunakan
- ✅ Sintesis suara (baca teks)
- ✅ Antarmuka responsif untuk tablet/desktop
- ✅ Bahasa Indonesia penuh
- ✅ Font besar dan kontras tinggi untuk kemudahan membaca

## Tech Stack
- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** JSON (MVP)
- **Deployment:** Railway (backend) + Vercel (frontend)
- **Version Control:** GitHub

## Setup Lokal

### Backend
```bash
cd backend
npm install
npm start
```
Server berjalan di `http://localhost:5000`

### Frontend
```bash
cd frontend
npm install
npm run dev
```
App berjalan di `http://localhost:5173`

## Deployment
- Frontend: Vercel (atau Railway static)
- Backend: Railway
- GitHub: Public repo untuk kolaborasi
